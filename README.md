## The Story

It started with a simple observation: **the best software doesn't feel like software.**

It feels like a letter from a friend. A photo album that remembers for you. A quiet tool that stays out of your way until the exact moment you need it.

**Labs & Drops** is an independent software studio born in Santiago, Chile, built on two beliefs:

🔬 **Labs** — Every product begins as an experiment. We prototype relentlessly, question every assumption, and ship only what we'd use ourselves.

💧 **Drops** — Great software arrives like rain: one drop at a time. No bloat. No dark patterns. No "subscribe to continue." Just honest tools that do one thing exceptionally well.

We don't chase trends. We build for the long haul — privacy-first, local-first, and always open about how things work.

## 🚀 What We've Built

### ❤️ [Heartbeats Memories](https://labsndrops.dev/apps/heartbeats/)
> *Because every moment deserves to be remembered — not stored.*

A desktop & mobile app that transforms your photos, music, and dates into living countdowns. Birthdays, anniversaries, milestones — Heartbeats turns time into something you can feel.

- 🔒 **Privacy by design** — Your memories never leave your device
- 📸 **Photo + Music + Countdown** — A sensory experience, not just a calendar
- 💻 **Cross-platform** — Web, Desktop (Tauri), and Mobile-ready
- 🌐 **Open source core** — Inspect it, fork it, make it yours

**[→ Try it now](https://labsndrops.dev/apps/heartbeats/)**

## 🧠 Philosophy

| Principle | What it means |
|---|---|
| **Local-First** | Your data lives on YOUR device. Cloud is optional, never mandatory. |
| **No Telemetry** | We don't track you. Period. No analytics, no "anonymous usage data," no exceptions. |
| **Open Source** | Transparency isn't a feature — it's a promise. Our code is auditable. |
| **Honest Pricing** | Pay once. Own it forever. No subscriptions for tools you already paid for. |
| **Accessible** | Beautiful software should work for everyone, everywhere. |
